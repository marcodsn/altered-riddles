## Scoped answer interpretation

Supervisor-approved `astra-answer-interpretation-v1` applies only to these 15
exact answers, not automatically to all historical scores:

1. Grade substantive commitments, not incidental alias mentions or rejected options.
2. Unresolved incompatible answers are `other`; explicit withdrawal or a clear
   final recommitment can resolve them. Position/parentheses alone cannot.
3. Hypothetical alternatives do not displace an unconditional answer.
4. Incidental “trick/modified” wording does not erase substantive answers. Bare
   premise rejection is `abstain`; a committed canonical answer can be `original`.
5. Bad explanation alone need not invalidate an identifiable answer **only when it
   does not change the selected object or violate a distinguishing constraint**.
6. Item-validity concerns remain separate from answer labels.
